# OLX Watcher

Следит за поиском на OLX и присылает уведомление, как только появляется новое объявление.
Работает с любым доменом OLX (`olx.ua`, `olx.pl`, `olx.ro`, `olx.bg`, `olx.kz`, `olx.pt`) и с любыми фильтрами.

Есть веб-интерфейс и сборка в один `.exe` — Node.js для запуска не нужен.

## Запуск

**Из готового exe:** двойной клик по `dist\OLX Watcher.exe`. Откроется браузер с интерфейсом,
слежение начнётся само. Окно консоли закрывать нельзя — оно и есть приложение.

**Из исходников:**

```bash
cd D:\SomeVibcodeShit\olx-watcher && npm start
```

Интерфейс — http://127.0.0.1:8777

## Как это работает

Фильтры настраиваются **на самом сайте OLX**: город, цена, комнаты, район — что угодно.
Ссылку из адресной строки надо вставить в приложение.

Дальше оно один раз разбирает эту страницу, достаёт из неё внутренний JSON-API OLX
со всеми уже применёнными фильтрами и опрашивает только его — это быстро и не грузит сайт.
Объявления идут «сначала новые», а увиденные ID запоминаются, поэтому одно и то же
объявление не придёт дважды.

Первая проверка запоминает текущую выдачу как базу и **молчит** — иначе сразу прилетело бы
полсотни уведомлений. Дальше приходит только то, что появилось после запуска.

## Интерфейс

- **Лента** — всё, что подошло под фильтры: фото, цена, площадь, район, частник или агентство.
  Клик открывает объявление на OLX.
- **Поиски** — добавить, отредактировать, включить или выключить поиск.
  Кнопка «Проверить фильтры» сразу показывает, что находится по текущим настройкам,
  а если ничего не находится — пишет причину по каждому отсеянному объявлению.
- **Настройки** — интервал, каналы уведомлений, Telegram.
- **Журнал** — что происходило. Первое место, куда смотреть, если что-то не так.

Изменения применяются сразу, перезапуск не нужен (кроме смены порта).

## Уведомления

**Windows** — всплывающий тост, клик открывает объявление в браузере.
Если не появляются: Параметры → Система → Уведомления, проверь «Не беспокоить»
и что уведомления разрешены для Windows PowerShell.

**Telegram** — самое полезное: приходит на телефон, даже когда ты не за компьютером.

1. Напиши [@BotFather](https://t.me/BotFather), команда `/newbot`. Он выдаст токен.
2. Впиши токен на вкладке «Настройки», включи галочку Telegram, сохрани.
3. Напиши боту `/start`. Пока chat id не настроен, он в ответ пришлёт твой chat id.
4. Впиши этот chat id туда же и сохрани.
5. Нажми «Проверить уведомления».

### Несколько аккаунтов

В поле Chat ID можно перечислить несколько id через запятую — например, если квартиру
ищете вдвоём. Тогда:

- уведомления о находках приходят **всем** перечисленным
- команды принимаются от **любого** из них
- если кто-то меняет состояние (`/pause`, `/off 1`), остальным приходит короткое
  оповещение, чтобы не гадать, почему бот замолчал
- `/last` и `/status` отвечают только тому, кто спросил

Фильтры, история и лента — общие: приложение одно, значит и «это объявление мы уже
видели» одно на всех. Второй копии приложения запускать не надо (и нельзя — см. ниже).

Чтобы добавить человека: пусть напишет боту `/start`. Ответа он не получит — так и задумано,
иначе любой посторонний понимал бы, что бот живой. Зато в журнале приложения появится строка
`боту написал чат 123456789 (Имя @username) — его нет в списке`. Берёшь оттуда id, дописываешь
через запятую на вкладке «Настройки», сохраняешь — и человек в деле. Перезапускать не нужно,
бот подхватывает изменение сразу.

### Команды бота

Тем же ботом можно управлять слежением с телефона — галочка «Отвечать на команды».

| Команда | Что делает |
|---|---|
| `/status` | Слежу или нет, когда следующая проверка, счётчики по поискам |
| `/last` | Последние находки. Можно указать сколько: `/last 10` |
| `/check` | Проверить прямо сейчас |
| `/pause` / `/resume` | Приостановить и продолжить слежение |
| `/searches` | Список поисков с номерами |
| `/on 1` / `/off 1` | Включить или выключить поиск по номеру |
| `/help` | Список команд |

Бот слушается только тех чатов, чьи id указаны в настройках — посторонний, наткнувшийся
на бота, не получит вообще никакого ответа. Работает на long polling, никакие webhook
и внешние адреса не нужны.

**Только одна копия приложения на один токен.** Telegram разрешает лишь одного слушателя
`getUpdates`: две запущенные копии выбьют друг друга ошибкой 409, команды начнут теряться,
а уведомления задвоятся. Второй экземпляр и не нужен — бот и так доступен с любого
устройства. Если очень надо на двух машинах, заведи второго бота со своим токеном.

Токен лежит в `config.json` открытым текстом. Если он куда-то утечёт — просто отзови его
в @BotFather (`/revoke`) и впиши новый.

## Фильтры

Это фильтры **поверх** тех, что уже зашиты в ссылку — для того, чего на сайте нет.

| Фильтр | Что делает |
|---|---|
| Цена, площадь, этаж | Диапазоны. Пусто — не ограничивать |
| Комнаты | Ничего не отмечено — любые |
| Стоп-слова | Отбросить, если слово встретилось в заголовке или описании |
| Обязательные слова | Оставить, только если есть хотя бы одно |
| Районы | Белый и чёрный списки, совпадение по части слова |
| Только частные | Отсеять риелторов и агентства |
| Только «без комиссии» | По отметке в объявлении |
| Не старше, минут | Не уведомлять про старые объявления |

**Про «не старше».** OLX подмешивает в выдачу платные «поднятые» объявления на фиксированных
позициях, и они ротируются при каждом запросе. Формально для приложения они новые, хотя висят
месяцами. Ограничение по возрасту их отсекает, а настоящее свежее платное объявление проходит.
По умолчанию 2880 минут (двое суток) — не выключай без причины.

## Команды в консоли

Пригодятся, если хочется без интерфейса.

| Команда | Что делает |
|---|---|
| `npm start` | Интерфейс + слежение (основной режим) |
| `npm run watch` | Только слежение, без интерфейса |
| `npm run once` | Один проход и выход — удобно для Планировщика задач |
| `npm run once -- --verbose` | То же, но с причинами отсева |
| `npm run test` | Показать текущую выдачу по фильтрам, ничего не запоминая |
| `npm run test-notify` | Тестовое уведомление во все включённые каналы |
| `npm run reset` | Забыть историю — следующий запуск снимет базу заново |

## Сборка exe

```bash
cd D:\SomeVibcodeShit\olx-watcher && npm install && npm run build
```

Получится `dist\OLX Watcher.exe` (~88 МБ — это вес самого движка Node внутри).
Собирается так: `esbuild` склеивает исходники в один файл, штатный механизм Node
(Single Executable Application) пакует его в blob, `postject` вшивает blob в копию `node.exe`.

Файл можно скопировать куда угодно и запускать там — `config.json`, `state.json` и `feed.json`
создадутся рядом с ним при первом запуске.

При сборке `postject` пишет `warning: The signature seems corrupted!` — это ожидаемо:
у `node.exe` есть цифровая подпись Windows, и она перестаёт совпадать после вставки кода.
На работу не влияет. Убрать предупреждение можно только `signtool` из Windows SDK
(в системе его нет), но смысла в этом мало — файл собран локально, а не скачан.

## Автозапуск вместе с Windows

Планировщик заданий → создать задачу → триггер «При входе в систему» → действие «Запуск программы»:

- Программа: `D:\SomeVibcodeShit\olx-watcher\dist\OLX Watcher.exe`

Чтобы окно консоли не мозолило глаза, в свойствах задачи можно поставить «Выполнять для всех
пользователей» — тогда оно свернётся в фон.

## Если что-то пошло не так

**«Не удалось разобрать страницу поиска»** — ссылка ведёт на конкретное объявление,
а не на список результатов.

**Ничего не находится** — фильтры слишком строгие. Кнопка «Проверить фильтры» на вкладке
«Поиски» покажет причину по каждому объявлению.

**«Порт 8777 уже занят»** — приложение уже запущено. Открой http://127.0.0.1:8777
или смени порт в настройках.

**Уведомления перестали приходить** — если OLX начнёт отдавать `403`, приложение само
переключится на разбор HTML-страницы. Если это повторяется, увеличь интервал проверки.
